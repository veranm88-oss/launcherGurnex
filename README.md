# Gurnex — лаунчер для Minecraft

Красивый лаунчер на Electron: белая и серая темы, плавные анимации, выбор и скачивание версий,
встроенные моды на Fabric и тихая фоновая мелодия, которую можно выключить.

## Запуск

```bash
npm install
npm start          # десктопное приложение (Electron)
npm run dev        # только интерфейс в браузере: http://localhost:3000
```

## Что уже есть

- **Главная** — кнопка «Играть», выбор версии, статус загрузки и запуска.
- **Версии** — настоящий список версий с серверов Mojang: релизы, снапшоты, альфа/бета, поиск.
- **Моды** — встроенная сборка (Sodium, Lithium, Iris, Xaero's Minimap, JEI и др.) с переключателями.
- **Настройки** — ник, оперативная память, размер окна, Java, тема, анимации, музыка.
- **Музыка** — тихая блюзовая тема в настроении «Me and the Devil», кнопка вкл/выкл и громкость в боковой панели.
  Чтобы играл оригинальный трек, положи свой файл в `src/assets/music/theme.mp3` или выбери его в настройках.
